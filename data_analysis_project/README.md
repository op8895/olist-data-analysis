# 巴西电商 Olist 数据分析项目

> Kaggle 真实数据集 | 99,441 笔订单 | SQL + Python + Pandas

---

## 一、项目概述

Olist 是巴西最大的电商平台之一。这个数据集是他们在 Kaggle 上公开的 2016-2018 年真实交易记录。

我做了三个分析：

| 项目 | 回答什么问题 | 方法 |
|------|------------|------|
| **GMV 归因** | 卖了多少钱？靠什么卖的？ | 连环替代法 + 多维下钻 |
| **满意度驱动** | 客户为什么打高分/低分？ | 配送时效 vs 评分对比 |
| **履约效率** | 送得快不快？哪个州拖后腿？ | SLA 达成率 + 排名 |

---

## 二、数据结构

### 核心就是六张表

```
客户下单 → orders（订单表：谁、什么时候、送到了没）
    ├── order_items（这单买了啥：商品ID、价格、运费）
    │       └── products（商品详情：品类名称）
    ├── customers（客户住哪：城市、州）
    ├── payments（怎么付的：信用卡还是现金、分几期）
    └── reviews（打几分：1-5星）
```

### 关键字段（只看这些就够了）

| 字段 | 含义 | 例子 |
|------|------|------|
| `order_purchase_timestamp` | 下单时间 | 2017-10-02 |
| `order_delivered_customer_date` | 实际送达 | 2017-10-10 |
| `order_estimated_delivery_date` | 承诺送达 | 2017-10-18 |
| `price` | 商品价格 | R$58.9 |
| `freight_value` | 运费 | R$13.29 |
| `review_score` | 客户评分 | 1-5 星 |
| `customer_state` | 客户所在州 | SP（圣保罗） |

**GMV = price + freight_value**（商品价格 + 运费）

**配送天数 = 实际送达 - 下单时间**

**延迟天数 = 实际送达 - 承诺送达**（负数 = 提前到，正数 = 迟到）

## 三、分析结果

### 项目 1：GMV 多维归因

**数据：** 96,478 笔已交付订单，总 GMV = R$1,542 万

**方法：连环替代法**

```
GMV = 订单量 × 每单商品数 × 商品均价
```

**跑出来的结论：**

1. **圣保罗州（SP）贡献 37.4% GMV**，是第二名里约（RJ, 13.3%）的 3 倍
2. **健康美容品类 GMV 最高**（9.2%），手表礼品其次（8.2%）
3. **信用卡占支付方式 75%**，分期付款客户 GMV 明显更高
4. GMV 月环比波动主要由订单量驱动

**面试怎么讲：**
> "连环替代法就是把 GMV 拆成三个乘起来的因子，依次替换算出各自贡献。我发现订单量是 GMV 波动的主驱动。下钻后发现圣保罗州占了近四成 GMV——如果圣保罗出问题，整体 GMV 必然受影响。"

---

### 项目 2：客户满意度驱动

**数据：** 110,013 条评价，5 星占 58%，1 星占 11%

**方法：** 配送时效 vs 评分对比分析

**跑出来的结论：**

| 评分 | 平均配送 | 准时率 |
|------|---------|--------|
| 5 星 | 10 天 | 97% |
| 4 星 | 12 天 | 96% |
| 3 星 | 14 天 | 91% |
| 2 星 | 15 天 | 83% |
| **1 星** | **19 天** | **68%** |

**准时率从 5 星的 97% 断崖式降到 1 星的 68%——配送延迟是差评最大的驱动因子。**

另外：
- 图书类满意度最高（4.51），办公家具最低（3.52）
- 高价格段（>R$500）准时率低但评分不差 → 高价用户对配送更宽容

**面试怎么讲：**
> "我把评分和配送时效做了交叉对比。5 星订单准时率 97%，1 星只有 68%——差了近 30 个百分点。配送延迟是差评的核心原因。但有意思的是，高价订单准时率偏低但评分不受影响，说明用户对贵重商品的配送预期不同。"

---

### 项目 3：履约效率分析

**数据：** 110,197 个已交付包裹，整体准时率 93%

**方法：** 月度/州/品类三维 SLA 达成率

**跑出来的结论：**

1. 最快州（AM）：准时率 96%，最慢州（AL）：准时率 77%
2. 食品配送最快（9 天），办公家具最慢（20 天）
3. 94% 订单在 21 天内送达
4. 2017-11（黑五）准时率骤降到 87% → 大促期间物流承压

**面试怎么讲：**
> "整体准时率 93% 看起来不错，但拆到州就发现问题——最差的 AL 只有 77%。而且黑五期间准时率降了 10 个百分点。建议大促前在准时率低的州预置库存，办公家具这类重品类考虑本地仓。"

## 四、你会被追问的问题

### Q1: 连环替代法和直接做减法有什么区别？

因为 GMV = A × B × C 是乘在一起的，因子之间有交互效应。直接拿单因子前后差值算会漏掉交互部分。连环替代法依次替换，三个贡献加起来精确等于总变化。

### Q2: 为什么转化率是 1.0？

这个数据每个客户只有一笔订单，所以 `订单量 / 客户数 = 1`。我的归因公式改成了 `GMV = 订单量 × 每单商品数 × 商品均价`，避开了这个问题。

### Q3: 准时率怎么算的？

`实际送达 <= 承诺送达` 就算准时。Olist 的承诺送达时间偏保守（平均承诺 23 天，实际 12 天），所以准时率 93%。但这不等于物流快——只是 deadline 设得宽松。

### Q4: 反馈评分和满意度相关，会不会是反向因果？

有可能。收到好评的订单可能是因为体验好 → 准时送达就是体验好。我和项目三交叉验证了——差评订单的准时率只有 72%，配送延迟是独立于评分的客观指标。

### Q5: 你最大的收获是什么？

平均数的欺骗性。整体准时率 93% 看起来没问题，拆到州才发现最差的只有 77%。如果只看总 GMV 和总准时率做决策，会漏掉圣保罗的集中风险和偏远州的物流问题。
